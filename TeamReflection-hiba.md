# Team Reflection – Hiba

## 1. What went well for you during the team sprint?

I think the teamwork went well overall because everyone worked on different parts of the project and communicated through GitHub and Microsoft Teams. My part was the shopping cart page and I was able to finish the add to cart, remove item, and quantity buttons successfully.

## 2. What would you do differently next time in terms of communication, process, or code?

Next time, I would probably communicate more with the team before starting the design part so everything matches better from the beginning. I would also push my updates more often while working.

## 3. What did you learn about working in a dev team?

I learned that working in a dev team requires communication and organization. I also learned how useful GitHub branches and pull requests are when multiple people are working on the same project.

## 4. How confident are you in contributing to a real team project after this experience?

I feel more confident now compared to before starting this project. I got more experience using React, fixing errors, and working with GitHub in a team environment.
