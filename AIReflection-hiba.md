# AI Reflection – Hiba

## 1. How did you leverage AI in your components?

I used AI sometimes for small ideas and troubleshooting while building the shopping cart page. I mainly used it to help me understand some React logic and improve parts of the UI, but I still made changes myself to fit the project requirements and design.

## 2. How did you understand, verify, and adapt the code?

I tested the code directly in the browser and checked if the cart functions worked correctly. I fixed errors step by step and adjusted the styling so it matched the rest of the project. I also verified that the quantity buttons and total price updated properly.

## 3. What did you learn or get better at by leveraging AI?

I improved my understanding of React state management, especially using useState for updating cart items dynamically. I also became more comfortable debugging issues and working with GitHub branches and pull requests.
